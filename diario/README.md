# Diário de treino

Um arquivo por semana: `diario/AAAA/semana-XX.md` (copie o modelo abaixo). Leva 2 minutos por treino e é o que permite ao coach ajustar o plano.

Quando quiser feedback, me diga: "coach, revisa a semana XX" — eu leio o diário e ajusto.
